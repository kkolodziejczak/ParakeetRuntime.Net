# Support

ParakeetRuntime.Net is a community-maintained open-source project. Support is best-effort, through
this GitHub repository.

## Start here

1. Read the [README](README.md), especially the model and requirements sections.
2. Check the model file's SHA-256 against the value in the README.
3. Search [existing issues](https://github.com/kkolodziejczak/ParakeetRuntime.Net/issues).

## Open an issue

Use the [bug report form](https://github.com/kkolodziejczak/ParakeetRuntime.Net/issues/new?template=bug_report.yml)
for reproducible problems and the
[feature request form](https://github.com/kkolodziejczak/ParakeetRuntime.Net/issues/new?template=feature_request.yml)
for proposals. A useful report includes:

- the version, and whether you use the exe, the NuGet package, or a source build;
- Windows version, processor and graphics, and whether the CPU or GPU path ran;
- the model file name and SHA-256;
- the smallest command or code that reproduces it, with expected and actual output.

## Protect private data

Never post recordings or transcripts of real conversations. Reproduce the problem with synthetic
audio or a public sample instead.
